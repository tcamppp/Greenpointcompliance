# greenpointcompliance.com

Static site. Deploy the contents of `site/` to Cloudflare Pages (or any static host).
No build step is required at deploy time.

## Files

| File | Notes |
|---|---|
| `index.html` | Homepage. Inline four-fifths calculator, enforcement-gap graphic, FAQ. |
| `nyc-local-law-144-bias-audit-guide.html` | Long-form LL 144 guide. |
| `four-fifths-rule-calculator.html` | Standalone calculator tool. |
| `services.html` | Engagements and pricing. |
| `about.html` | Practice, independence, the six questions, founder bio. |
| `legal.html` | Terms, independence statement, privacy. |
| `styles.css` | Shared stylesheet for every page. |
| `taylor-campbell.jpg` | Founder photo used on About. |
| `taylor-campbell-square.jpg` | Open Graph / social preview image. |
| `sitemap.xml`, `robots.txt`, `_headers` | Crawl and security headers. |

`_headers` is Cloudflare Pages syntax. On another host, port those headers manually.

## Changed in this refresh

- Canonical domain is now `greenpointcompliance.com` throughout; contact is
  `hello@greenpointcompliance.com`. Point the old `greenpointaicompliance.com`
  at a 301 redirect if it is indexed.
- `ai-hiring-laws-by-state.html` was removed. **Add a 301 from that path to
  `/nyc-local-law-144-bias-audit-guide.html`** so existing links and any
  accumulated search equity are preserved.
- All service delivery timeframes removed. Statutory timeframes (10-business-day
  notice, 12-month audit window, 6-month posting) are retained, as is the free
  twenty-minute scoping call.
- Type is now Libre Franklin / Newsreader / IBM Plex Mono.
- Six custom SVG diagrams, no stock imagery.

## Editing

`styles.css` is shared, so a change there applies to every page.

The HTML is generated by `_build.py`, which holds the shared header, footer,
nav, FAQ and the six auditor questions in one place. `_gen_svg.py` generates the
diagrams into `_svg/`. To regenerate after editing either:

    python3 _gen_svg.py && python3 _build.py

Editing the `.html` files directly also works. If you do that, stop using the
build script, or it will overwrite your changes.

## Facts and citations

The enforcement figures come from the Office of the New York State Comptroller,
report 2024-N-6, published 2 December 2025, covering July 2023 through June 2025:
32 companies reviewed, 1 instance of non-compliance identified by DCWP, at least
17 potential instances identified by the Comptroller, 2 AEDT complaints received,
75% of test 311 calls misrouted.
